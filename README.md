# Алексей Поздняков (AVPscan)
**Архитектор операционных систем реального времени | Низкоуровневый системный программист**

Разработка суверенного, независимого программного обеспечения и альтернативных архитектур вычислительных систем. Полный отказ от стандартов POSIX, коммерческих шаблонов и унаследованной календарной лжи в пользу чистой физики и тригонометрии.
## 🧬 Программы не зависят от:
- операционной системы `terminal/sys_*.c` для демонстрации на текущих осях
- видеокарты `Fps` просто константа `var.Loop = (Base.Apm * Base.Hz) / Base.FTime`
- процессора `32/64/...Cell` автоадаптация
- монитора `8k/16k/32k/...CellPow` автоадаптация
- гео-адаптивная система `Base.Hz` частоте питающей сети `UTF8` полная поддержка без библиотек автоадаптация
- цветность математически разложен спектр исходя из глубины автоадаптация
- «экосистем» `Libc` по сути лишнее

## Ключевой проект разработки

### 🚀 [Fresh-ОС](https://github.com/AVPscan/Fresh)
**Суверенная высокодетерминированная RTOS / HAL-монолит**
* **Вселенский хронометр**: Полное уничтожение ватиканских Григорианских/Юлианских костылей. Время, високосы и орбита нарезаются без ветвлений в один такт процессора через 5 базовых констант планеты на аппаратных битовых сдвигах. Смена суток, недель и лет жестко заперта на истинный астрономический полдень (зенит солнца).
* **Событийная модель RTOS**: Неблокирующий буферизированный сквозной ввод устройств (клавиатура, мышь, колесо прокрутки, системные прерывания) с жесткой наносекундной стабилизацией кадра (`CLOCK_MONOTONIC`) и аппаратной поддержкой горячей замены узлов питания (Hot-Swap).
* **Волновая тригонометрическая графика**: Математический холст, работающий на чистых функциях `sin`, `cos`, `tg`, `ctg` без пиксельных массивов. Концепция векторных окон-спрайтов (координатные дескрипторы `rvgoc`) с поддержкой послойного CRS-рендеринга до 65 535 активных слоев в пространстве.
* **Абсолютный HAL**: Полная изоляция ядра. Текущий кроссплатформенный запуск (Linux, Windows/MinGW, macOS, FreeBSD) — лишь отладочный слой. Система побитово готова к мгновенной миграции на голое железо (bare-metal) бортовых компьютеров.

## Инженерный стек и специализация
* **Языки**: Кристально чистый низкоуровневый Си (без сторонних тяжелых библиотек), ассемблер, препроцессорные макросы автоматического подсчета аргументов.
* **Области исследований**: Астрофизические инварианты времени, целочисленные алгоритмы сближения корней, послойный безветвенный рендеринг графических спрайтов, кроссплатформенная оптимизация линковки реального времени (`-flto`, `-lwinmm`).
* **Философия разработки**: Минимизация тактов процессора, экономия кремния, полный контроль над памятью и регистрами, предсказуемость рантайма в любой точке Вселенной.

### [Products](https://github.com/AVPscan/Products) — умные покупки и аналитика

57 КБ. Полноценное приложение для учёта покупок, аналитики цен и отправки отчётов.

- Быстрый ввод трёх полей (количество, цена, название)
- Автодополнение из словаря
- Аналитика средневзвешенных цен
- HWID-привязка и шифрование данных (почта/пароль не хранятся в открытом виде)
- Автоматическая отправка отчётов на email
- Кроссплатформа (Linux/Windows/macOS)
